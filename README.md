# 🛍️ Myntra E-Commerce Website – Manual Testing Project

## 📌 Project Overview

This project focuses on manual testing of the Myntra e-commerce website.
The objective is to validate important e-commerce functionalities, identify
potential defects, document test results, and prepare software testing
documentation.

The project covers functional testing, UI testing, validation testing,
negative testing, compatibility testing, and basic performance checks.

---

## 🎯 Project Objectives

- Understand the functionality of an e-commerce website.
- Prepare and execute manual test cases.
- Validate positive and negative scenarios.
- Identify and document defects.
- Track test execution results.
- Prepare a Requirement Traceability Matrix (RTM).
- Generate a Test Summary Report.
- Maintain testing documentation using Excel and CSV files.

Sample bug reports cover scenarios such as:

- Show Password button not functioning correctly

- Invalid email accepted without validation
- Irrelevant products displayed in search results

- Wishlist items disappearing after re-login
- Product not added to the shopping bag
- Incorrect coupon discount calculation
- Order details not displayed
- Return request submission failure
